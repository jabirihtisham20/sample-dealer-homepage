Demo vehicle photos (hero.jpg, car-1.jpg … car-6.jpg) belong in this folder.

They are included in the downloadable project zip (sample-dealer-homepage-nextjs.zip)
provided by Velix Web Studio. They are not stored in this Git branch because the
GitHub app connection used to push this project supports text files only.

To complete a clone of this branch: copy hero.jpg and car-1.jpg … car-6.jpg from
the zip's public/images folder into this folder, then run `npm install && npm run dev`.
